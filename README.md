# PP Research Tracker

Portfolio tracker komunity **Pod Pokličkou Research**: akcie, ETF, krypto, komodity i hotovost na jednom místě.

## Stažení
👉 **[Stáhnout nejnovější verzi](https://github.com/martyycz4/pp-research-tracker-releases/releases/latest)**: soubor `PP-Research-Tracker_…_x64-setup.exe`

**Instalace:** spusť stažený soubor. Windows může ukázat okno „Systém Windows ochránil váš počítač“, klikni na **Další informace → Přesto spustit**. Další aktualizace se nainstalují samy přímo v aplikaci.

## Co umí
- Přehled portfolia ve více měnách včetně hotovosti
- Import z Trading 212 a XTB
- Výkonnost: zhodnocení, XIRR, TWR, srovnání s indexy, měsíční výnosy
- Detail aktiva, 3letý časový test, loga společností, zálohy dat

Všechna data zůstávají jen ve tvém počítači. Aplikace neslouží jako investiční poradenství.
